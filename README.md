## About

I design and ship **AI-powered systems and intelligent workflows** — the kind that quietly remove work instead of adding another dashboard to check.

Most of what I build shares three convictions:

- **Local-first by default.** Your data should not need to leave your device to be useful. Several of my tools run 100% in the browser with no backend at all.
- **Answer, don't decorate.** A verdict beats a chart. A countdown beats a spreadsheet.
- **The best problems are invisible.** Not the ones everyone is solving — the ones everyone has learned to live with.

I write about digital systems, security, and the realities of AI in software at **Digital Brings Insights**.

## 🤖 AI Business Toolkit

Six focused tools that automate the unglamorous parts of running a business.

| Tool | What it does |
|------|--------------|
| [**Business RAG Chatbot**](https://github.com/ramsai676/ai-business-rag-chatbot) | Embeddable support chatbot answering from a company's own FAQ via BM25 retrieval, with citations. One script tag to embed. |
| [**Lead Generator**](https://github.com/ramsai676/ai-lead-generator) | Finds local businesses from OpenStreetMap and ranks them as sales leads — no-website businesses score highest. CSV export. |
| [**Outreach Automation**](https://github.com/ramsai676/ai-outreach-automation) | Generates tailored cold outreach for email, WhatsApp and SMS, plus a custom landing-page mockup, from one business profile. |
| [**Phishing Detector**](https://github.com/ramsai676/ai-phishing-detector) | Flags phishing and scam attempts in email, SMS or chat with a risk score, the warning signs found, and a plain-English explanation. |
| [**Website Security Scanner**](https://github.com/ramsai676/ai-website-security-scanner) | Audits a site for common HTTP security misconfigurations and returns a graded report with the exact fix for each finding. |
| [**WhatsApp Automation Bot**](https://github.com/ramsai676/ai-whatsapp-bot) | Meta Cloud API bot: FAQ answering, multi-step lead capture, and human handoff — with a built-in simulator. |
